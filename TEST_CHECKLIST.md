# Review checklist

- Install in a clean Python 3.12 virtual environment; run pip check and pytest.
- Start app.py without a key. Confirm no automatic API requests and clear unresolved metrics.
- Build the separate demonstration. Inspect every floor, room access, source labels and warning.
- Change a requirement; confirm planning selection and downstream downloads become stale.
- Review API key/model settings and explicitly test a paid connection with your own key.
- Exercise a short live interview and a small layout request. Confirm returned JSON is validated, invalid geometry is blocked and retry/usage limits are observed.
- Verify actual authority/plot-category rules, official source clauses and effective dates before any compliance claim.
- Replace synthetic duration/crew/curing and MEP coefficients with project-specific reviewed inputs.
- Supply dated city-specific rate/wage quotations. Check unit conversions and composite-rate double counting.
- Verify known-subtotal versus complete-total behavior with missing prices and incomplete task reporting.
- Open PNG/DXF in a CAD viewer, GLB/OBJ in a mesh viewer and IFC in an independent IFC viewer.
- Review stair headroom, net clear room sizes, structural grid, accessibility, egress, ventilation, foundations and MEP with the appropriate professionals.
- Review the PDF on every page and open/recalculate the Excel workbook in the intended desktop application.
- Export before closing. Session metadata alone is not a full project backup.
- Add authentication, authorized database persistence and backups before any shared production deployment.
