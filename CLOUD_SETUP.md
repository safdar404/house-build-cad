# Streamlit Cloud setup

Use repository safdar404/house-build-cad, branch main, entrypoint app.py, and Python 3.12. requirements.txt belongs at the repository root beside app.py. All agents, tools, ui, pages and data directories must also be deployed.

If the prior deployment still reports a missing dotenv module, use Manage app → Reboot app and inspect the dependency installation log. The distribution name is python-dotenv; the Python import is dotenv. Do not paste API keys in logs or GitHub. Enter your key in the application sidebar or Streamlit secrets.

Start with the project form or the labelled no-key demonstration. AI interviews and layout generation require an API key and model ID.
